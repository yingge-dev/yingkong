# 颖控 · 安卓调度仪表台

> 先看清，再动手。

颖控是一款面向安卓深度用户的性能与功耗工具箱：实时监控、帧率记录、A/B 对比、性能档位、刷新率、温控、充电上限、应用治理和自动化，全部收在同一条时间线上。所有写操作先备份、再回读、失败自动还原。

**当前阶段：M1 可点原型（模拟数据，不会修改系统）。**

## 原型

- 在线体验：[https://yingge-dev.github.io/yingkong/](https://yingge-dev.github.io/yingkong/)（部署后生效）
- 本地打开：直接双击 `index.html`，或起一个静态服务器
- 手机访问体验最佳，支持添加到主屏幕

原型包含 5 个页面：

| 页面 | 能做什么 |
|---|---|
| 监控 | 实时 FPS / 1% low / 温度 / 功耗 / 负载，模拟数据每秒刷新 |
| 记录 | 调优前后 A/B 曲线、掉帧率 / 1% low / 温度差值、场次列表、导出 |
| 调优 | 游戏启动配方、性能档、刷新率（面板最高 / 跟随帧率 / 固定档）、安全校验 |
| 应用 | 搜索、筛选、冻结 / 解冻、待机分组、强制停止（模拟） |
| 设置 | 基础 / Shizuku / Root 权限模式、采样频率、数据导出、救援模式 |

## 设计

- 视觉方向「晨光」：浅色、玻璃、连续圆角、单一信号色，参考 Xiaomi HyperOS 与 Apple HIG 的方法，不做模仿。
- 字体：Inter（OFL）+ Noto Sans SC。
- 颜色：`#F2F2F7` / `#FFFFFF` / `#1D1D1F` / `#FF6900` / `#0A84FF`。
- 动效：数字滚动、曲线生长、底部弹层、触感反馈。

## 为什么不是又一个 Scene

Scene 的骨架是对的，但界面停在 2018 年，数据之间也不打通。颖控的差异：

1. **一条时间轴**：帧率、温度、功耗、充电、后台事件落在同一根轴上。
2. **能验证**：写入 → 回读 → 标「已核验 / 未生效」，失败自动回退。
3. **能对比**：调优前后两条曲线 + 差值 + 分享长图。
4. **配方存语义**：刷新率写「面板最高」，不写死 120；换机自动跟着走。
